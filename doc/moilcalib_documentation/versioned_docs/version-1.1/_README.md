# This folder = the CURRENT (unreleased) version

Right now this holds v1.1's content, tracking `main_development`. This folder is always "whatever's being drafted next" — when v1.1 is frozen, `npx docusaurus docs:version 1.1` copies this folder's contents into `versioned_docs/version-1.1/` automatically, and you keep writing the next draft right here in `docs/`. No renaming needed.

Files here are excluded from the built site (underscore-prefixed files are ignored by Docusaurus). This is a note for anyone browsing the repo, not a doc page.

See `/VERSIONING.md` at the repo root for the full folder map and how to cut a new version.
